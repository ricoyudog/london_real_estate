

### 商業背景

業務團隊需要定期、可靠地監察倫敦辦公室商業房地產（Commercial Real Estate，CRE）市場。

主要關注範圍包括：

- 優質（Prime）及甲級（Grade A）辦公室租金趨勢
- 空置率及可租用面積比例
- 租賃成交量與市場活動
- 未來供應管線，包括新發展項目、翻新項目及預租項目
- 不同子市場的動態，例如：
    - 倫敦金融城（City）
    - 西區（West End）
    - 金絲雀碼頭（Canary Wharf）
    - 中城及外圍地區（Midtown／Fringe）
- 宏觀經濟因素，例如利率、經濟指標及就業情況
- 租戶需求的主要推動因素，例如：
    - 「追求更高質素辦公空間」（Flight to Quality）
    - ESG／可持續發展要求
    - 混合辦公模式的影響
- 可能影響辦公室市場的新消息或重大事件

這個項目的目標，是協助業務團隊：

- 更早掌握市場變化
- 及早識別潛在風險與投資機會
- 支援管理決策、市場報告及策略討論
- 以自動化研究取代或補充人手資料搜集及靜態市場報告

### 任務

設計並交付一個以 Python 開發的 AI Agent，協助業務團隊監察倫敦辦公室市場。

你可以自行界定 Agent 的具體功能範圍，並建議採用「Skills／技能模組」的方式設計整體架構。

## 需求重點

### 1. 核心交付物

- 一個可以實際運行的 Python AI Agent
- 清楚的安裝、設定及使用說明
- 模組化的 Skills 架構，讓不同市場監察能力可以獨立擴充

### 2. 市場資料監察

Agent 至少應涵蓋部分以下指標：

- Prime／Grade A 租金
- 空置率及可用樓面
- 租賃成交量、主要租賃交易和市場活躍度
- 新建、翻新、預租及未來落成供應
- 各個倫敦子市場的表現差異

### 3. 外部影響分析

Agent 應能追蹤和分析：

- 英國利率及貨幣政策
- GDP、通脹、就業等經濟指標
- 企業辦公室需求
- 混合辦公趨勢
- ESG、能源效益及可持續建築要求
- 重大市場新聞、政策或交易事件

### 4. AI 分析能力

除了收集資料，Agent 應能：

- 摘要最新市場資訊
- 識別趨勢及異常變化
- 比較不同子市場
- 將新聞與市場指標建立關聯
- 提出潛在風險、機會及需要留意的事項
- 清楚標示資料來源、發布日期及可信程度
- 區分客觀事實與 AI 推論

### 5. 輸出方式

可以考慮提供：

- 每日或每週市場摘要
- 重大事件即時提示
- 市場指標表格或圖表
- 子市場比較報告
- 可供管理層閱讀的重點摘要
- 可供其他系統使用的 JSON／CSV 輸出

### 6. 建議的 Skills 模組

Agent 可以拆分成以下技能：

- `news_monitor`：搜尋及整理市場新聞
- `market_metrics`：收集租金、空置率及租賃數據
- `supply_pipeline`：追蹤新建、翻新及預租項目
- `macro_monitor`：追蹤利率及宏觀經濟指標
- `submarket_analysis`：比較不同倫敦子市場
- `trend_detection`：識別趨勢及異常變動
- `report_generator`：產生每日或每週報告
- `alerting`：在重要變化出現時發出提示
